Git: Local & Remote Repository

💻 Local Repository

Local Repository არის Git-ის პროექტის ასლი, რომელიც შენს კომპიუტერში ინახება.

აქ აკეთებ ცვლილებებს და ქმნი commit-ებს.

⬆ git push

☁️ Remote Repository

Remote Repository არის პროექტის ვერსია, რომელიც სერვერზე, მაგალითად GitHub-ზე, ინახება.

მისი საშუალებით შეგიძლია პროექტი სხვებს გაუზიარო.

რას აკეთებს git push?

git push აგზავნის Local Repository-ში გაკეთებულ commit-ებს Remote Repository-ში.

git push origin main

რას ნიშნავს origin?

origin არის Remote Repository-ის სტანდარტული სახელი Git-ში.

მაგალითად:

git push origin main

ეს ნიშნავს: „გააგზავნე main branch-ის ცვლილებები origin-ში.“
